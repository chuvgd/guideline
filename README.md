# guideline

本文档用于提供 “如何使用git/github/gitee” 的指南准则（guideline）。

1. 命名/创建仓库
   - 仓库名不要用vgd开头，如 `VGD-nav` 这种是不合适的，因为我们本来就叫chuvgd，访问也是用 github.com/chuvgd/xxxxx，如果你加一个就变成 chuvgd/vgd-nav 了，不免语义重复
   - 创建时默认是private的，不过大部分情况可以用public，除非真的需要隐藏。不然小登看不见队里代码
2. 禁止自己删除仓库，尤其不是你自己的，即使你有权限也请问老登在说，
3. 协作方式：
   其实git的协作方式已经有很多教程了，这里再大概讲一下，如果还不懂请自学或问老登：
   - 同仓库多人开发：你想新写东西时，自己新建一个分支，然后让指定一个人负责merge或提pr
   - 如果人更多/不想让他们能有权限直接操控仓库：fork到自己账号，再提pr
